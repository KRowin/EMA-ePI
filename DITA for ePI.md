# How DITA can help with ePI?
## DITA Open Toolkit
Let us have a look at the information on the [DITA Open Toolkit](https://www.dita-ot.org/) (DITA OT) about **Multichannel publishing** features.
It has out of the box support for transforming the content into (among others):
- HTML
- PDF
- Markdown
Tools like Oxygen XML suite have further transformation capabilities into e.g.
- Open XML
- Microsoft OXML
